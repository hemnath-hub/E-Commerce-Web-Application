# 🛒 MERN E-Commerce Web Application

A full-stack E-Commerce application built with MongoDB, Express.js, React.js, and Node.js.

## Features

- User Registration & Login
- JWT Authentication
- Product Listing
- Shopping Cart
- Order Management
- MongoDB Database Integration
- REST API Architecture

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- JWT
- Axios
- BcryptJS

## Installation

### Backend

```bash
cd backend
npm install
node server.js
